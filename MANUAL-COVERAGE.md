# Manual coverage and implementation notes

Implemented as individual source files:
- Unit 1: 24 simple programs, 6 if-condition programs, and 36 loop/series programs.
- Unit 2: 20 array exercises (including one menu-driven implementation of the manual's combined array operations), stack, linear queue, circular queue, 12 string exercises, and 5 pointer/matrix exercises.
- Unit 3: 8 function/recursion exercises and 7 structure exercises, including the manual's book, nested-address, student, bank-customer, marks and cricketer tasks.
- Unit 4: 4 file-handling exercises.

The manual's broad instruction “All the programs of Loop using recursion” does not enumerate each recursive variant; representative recursive sum and Fibonacci programs are included alongside recursive factorial. The loop pattern section has several diagrams whose spacing/layout is ambiguous in extracted document text; the included pattern files implement the legible sequence examples.
